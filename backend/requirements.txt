# Floor pins (>=) rather than exact pins (==).
#
# Several of these ship compiled wheels (pydantic-core, chroma-hnswlib, lxml).
# An exact pin has no wheel for any Python newer than the pin, so pip falls back
# to building from source and the install fails on a machine with no Rust/C++
# toolchain. Floor-pinning keeps the install working across Python versions,
# which is what the standalone scraper did too.
