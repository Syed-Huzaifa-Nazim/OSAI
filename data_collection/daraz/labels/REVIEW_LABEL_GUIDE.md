# Jewellery review reasons: label guide

Each review gets every reason it clearly mentions, with `+` (praise) or `-` (complaint), separated by `; `.
A review with no clear reason gets `none`. Read the WHOLE review. Roman Urdu and English are both common.

| Reason | `+` example | `-` example |
|---|---|---|
| `quality` | "quality achi hai", "material is good" | "quality bekar", "cheap material", "fake" |
| `colour_fade` | "colour nahi utra", "no fading after a month" | "2 din mein kala ho gaya", "colour utar gaya", "plating gone", "tarnished" |
| `stones` | "stones bohat shiny", "stones are well fixed" | "stone gir gaya", "stones missing", "stones loose" |
| `breakage` | "strong, did not break" | "toot gaya", "chain broke", "hook broken", "came broken" |
| `as_pictured` | "same as picture", "jaisi dikhai wesi mili" | "picture se different", "not as shown" |
| `wrong_or_missing` | — | "wrong colour sent", "1 piece missing", "4 ka bol ke 3 bheje" |
| `size_fit` | "perfect size", "fit ho gayi" | "size chota hai", "ring fit nahi hui" |
| `comfort` | "light weight", "comfortable to wear" | "bohat heavy", "allergy ho gayi", "kaan mein dard" |
| `design` | "beautiful", "pyari hai", "elegant design" | "design acha nahi" |
| `price_value` | "worth the price", "is price mein best" | "too expensive for this", "not worth it" |
| `delivery` | "fast delivery", "jaldi mil gaya" | "late delivery", "10 din baad mila" |
| `packaging` | "packing achi thi", "safe box" | "bad packing", "box toota hua" |
| `seller` | "seller cooperative", "good response" | "seller ne reply nahi kiya", "no return", "fraud" |

Rules:
- Only what the review says, not what the stars say (many 5-star reviews are complaints).
- "nice", "good product" alone = `none` (no reason given), except clear look words ("beautiful", "pyari") = `design+`.
- "fake" about the material = `quality-`; "different from picture" = `as_pictured-` (not quality).
- A gift/thank-you message with no reason = `none`.
